# 혼자놀기 MVP 보관함

이 디렉터리는 현재 "뭐할까" Match 앱에서 사용하지 않는 이전 "혼자 놀기(서울 코스 탐색)" MVP의 지도·코스 자산을 보관합니다.

- `components/`: 서울 지도, 자치구 탐색, 코스 카드 UI
- `data/`: 코스, 인접 자치구, 서울 자치구 경계 데이터
- 전체 실행 가능 스냅샷: GitHub 브랜치 `archive/honja-nolgi-mvp`
- 스냅샷 기준 커밋: `c0475b5`

현재 앱의 정본은 저장소 루트이며, 이 보관함의 파일은 런타임 코드에서 import하지 않습니다. 이전 MVP를 다시 실행하거나 별도 제품으로 분리할 때는 보관 브랜치에서 새 저장소나 새 작업 브랜치를 만드는 것을 권장합니다.
